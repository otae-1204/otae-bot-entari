# AKE 切换后：富文本与账号页修复

2026-09-05，基线 `84d439c`，继续使用 `refactor/project-architecture`。

## 修改内容

1. 干员、武器、装备详情共用富文本图标 CSS。移除原来的 15 / 11 / 17 像素固定正方形，改为随文本字号缩放、保留素材宽高比，并统一基线。AKE 图标常见画布为 44×36 且含透明边距，旧实现把实际符号进一步缩小；新画布高度为 1.25em。没有改技能数值、图片下载规则或主体布局。
2. `/ef 账号` 主线名称接入 AKE `TextTable → I18nTextTable_CN`，支持任务原始 ID、哈希 ID、文本键与数字文本 ID。官方只返回英文标题、没有任务 ID 时，复用既有挑战本地化模块的中英同 ID 精确对照缓存。已经是中文或任务 ID 已解析时不加载英文对照；源不可用仍展示原描述，不阻断账号页，也不改写官方响应。
3. 账号干员顺序改为 **等级降序 → 星级降序 → 角色 ID 降序**。官方提供哈希 ID 时，先通过 AKE 名称映射恢复原始角色 ID 再比较编号。其他页面的专用排序（如养成投入排序）不改动。

公共文本表约增加一次 2 MB 的冷下载，后续复用已有版本缓存与公共表磁盘缓存。纯英文标题的精确匹配使用原有中英对照缓存；缓存尚未准备好时需要等待其首次加载。没有按英文含义猜译或硬编码这一个标题。

`CARD_RENDER_VERSION` 升为 `endfield-card-v43`，避免沿用旧尺寸的成品图。账号图缓存继续包含完整视图内容，名称/顺序变化也会换缓存键。
