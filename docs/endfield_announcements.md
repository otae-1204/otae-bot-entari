# 终末地活动公告提醒

已接入国服官网公告。无需绑定游戏账号；群内订阅发到当前群，私聊订阅只发给订阅者。所有日期和提醒均按北京时间处理。

## 命令

```text
/ef 公告 帮助
/ef 公告 订阅
/ef 公告 订阅 活动 维护 签到
/ef 公告 提前 开始 60
/ef 公告 提前 结束 1440
/ef 公告 提前 维护 30
/ef 公告 提前 结束 关闭
/ef 公告 状态
/ef 公告 列表
/ef 公告 取消订阅
```

`公告` 可替换为 `活动提醒` 或 `announcements`。订阅类型支持 `全部`、`活动`、`维护`、`卡池`、`签到`、`其他`，多种类型用空格分隔；`其他` 指未归入前四类的官网公告。再次订阅会更新类型，保留已设置的提前时间。

开始、结束、维护分别默认提前 60、1440、60 分钟。可设置 1–10080 分钟，或用 `关闭` 停止对应的定时提醒；修改提前时间或关闭定时提醒，不影响正在等待投递的新公告。

群主、群管理员和 SUPERUSER 可以修改本群订阅。私聊只能管理本人的订阅，命令不接受指定其他群或用户的 ID。关闭本群 `endfield` 功能后，群推送暂停。订阅同时绑定平台和机器人账号，另一个账号上线不会接管它的投递。

## 数据来源与时间

来源为[终末地国服官网公告](https://endfield.hypergryph.com/news)。2026-10-01 核对官网前端并只读实测了它使用的 CMS 接口：

- 列表：`GET https://web-news.hypergryph.com/api/bulletin`
- 详情：`GET https://web-news.hypergryph.com/api/bulletin/{cid}`
- 公共参数：`lang=zh-cn`、`code=endfield_web`；列表另带 `page`、`pageSize`。
- `cid` 用作公告标识，`displayTime` 是发布时间，详情的 `data` 是 HTML 正文。

有订阅时每 10 分钟采集一次，每分钟检查待发消息。首次上线会触发检查；没有订阅时不定时采集，手动查看列表仍可读取。单轮最多读取 3 页、每页 20 条，关注最近 45 天、置顶公告和仍有未来日程的已知公告；详情最多 80 条，并发为 3。接口结构不符或某篇详情失败时保留上次完整快照，不把失败结果当成新基线。

只识别活动、开放、签到、寻访、申领和维护时间段中明确写出的完整年月日、小时和分钟。支持跨年及中文年月日格式；国服“服务器时间”按 UTC+8 解释。正文中的“版本更新后”“维护前”等表述不转换为推测时刻。仅有明确开始或结束时间时，只安排已知的一端。正文仅提到签到而未单独给出时间时，签到订阅仍能收到公告，但不会继承其他活动的时间。

版本总公告与单篇公告中的同名活动共用提醒标识，采用发布时间较新的公告日程。正文修订会撤销旧的待发提醒并重新计算；明确时间段被移除后，不用更旧的公告恢复该时间段。公告变更会另发一条更新摘要。每条推送附官网链接和公告发布时间。

## 首次订阅、恢复与清理

首次成功采集只建立该订阅的公告基线，不补发历史公告；未来日程仍会生成提醒。其他订阅已建立基线，不会改变新订阅的这一行为。

订阅、公告快照、发送队列和回执保存于 `data/endfield/announcements.db`，重启后继续使用。发送失败从 60 秒开始指数退避，最多间隔 30 分钟重试；某个目标失败不阻止其他目标发送。账号离线或群功能关闭时保留待发消息，不增加失败次数。

新公告最多补发 2 小时。定时提醒最多补发 2 小时，且必须仍在对应开始或结束时间之前。数据超过 30 分钟未成功更新时暂停投递。取消订阅会删除该订阅及其待发消息；过期记录按 90 天保留期清理。

发送成功后记录回执。若进程恰好在消息已送达、回执尚未落盘时退出，重启重试可能重复发送；平台未提供幂等发送保证，因此不承诺严格的“只发送一次”。

## 维护与验证

业务模块位于 `plugins/endfield/announcements/`；命令路由、启动、定时任务与清理注册保留在 `plugins/endfield/handlers.py`。SQLite 操作在线程中执行，各操作使用独立连接和事务。

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests/test_endfield_announcements.py tests/test_architecture.py tests/test_group_features.py tests/test_endfield_daily.py
```

新增测试使用离线夹具、临时数据库和模拟发送器，覆盖参数错误、权限、时区、不确定时间、重复公告、正文修订、跨公告日程去重、撤回日程、重启恢复、失败退避、过期清理、多账号隔离与群功能开关。架构测试另外使用真实 Entari 分发命令，但不连接 QQ。

官网接口已进行只读实测；真实 QQ 群和私聊投递仍需部署配置后验收。
