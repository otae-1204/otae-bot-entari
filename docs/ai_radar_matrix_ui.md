# AI 智商雷达 · 模型档位矩阵

总览采用暖米白与橄榄绿，保留国内外与研发厂商分组，把所有模型放在一张长图内。2026-09-15 调整了模型卡片的视觉层级与细节，并统一卡宽；只有一个模型的厂商也占正常的一列。

## 布局与风格

画布宽 1960 px，高度随模型数量增长。暖灰米色画布承托乳白卡片，圆角和细边框形成轻量分层；国内外区域使用深绿标题带。保留 `card.css` 的字体和品牌栏，在 `matrix.css` 中集中定义本版的颜色与组件样式。每块卡片按以下顺序阅读：

1. 卡头集中放模型图标、名称、完整模型 ID，右侧标明实际档位数量。
2. 模型 IQ 与末点样本量、时间并排，下方横向展开趋势图。去掉独立图框与大色块，使用细轴线、浅网格和单行刻度，完整起止时间单独收在图下。
3. 档位区按 `ultra → max → xhigh → high → medium → low` 排列，每格从上到下为档位名、IQ、通过率 / F1 与样本数、耗时和费用。
4. 更新时间收在卡片底部，文字对比度与字号低于主数据。

档位格使用柔和浅绿底，大字分数优先，证据紧随其后，底部两列分别放耗时与费用。减少纵横分隔线，只在表现与投入之间保留一条细线。2026-09-16 将 IQ 颜色改为按分数连续映射，模型整体 IQ 与各档位 IQ 共用一套色标；档位名恢复统一的中性色。移除档位格右上角重复的短横线。六档为 3×2，五档为三列排两行，四档为 2×2，三档一行，两档左右并排；末行不补空档。手机 HTML 为单列模型、最多两列档位。

## IQ 分数色卡

参考 [ColorBrewer RdYlGn](https://colorbrewer2.org/#type=diverging&scheme=RdYlGn&n=11) 的红、橙、黄、黄绿、绿的色相顺序。[D3 官方文档](https://d3js.org/d3-scale-chromatic/diverging#interpolateRdYlGn)提供该色卡的连续插值形式，[官方色值定义](https://github.com/d3/d3-scale-chromatic/blob/main/src/diverging/RdYlGn.js)包含 11 色版本。本页采用为米白底文字调整的深色变体，避免原色卡中间的浅黄色难以辨认；不是直接复用原色值。

固定 IQ 0–150，每 15 分一个控制点，共 11 个，相邻控制点之间按 RGB 连续插值。控制点只用于颜色映射，不定义能力、及格线或置信度。全页固定同一范围，避免每张卡按自己的最低、最高分着色导致同分异色。

| IQ 控制点 | 字体颜色 |
| --- | --- |
| 0 | `#b33237` |
| 15 | `#b33c30` |
| 30 | `#af4e29` |
| 45 | `#a45f1f` |
| 60 | `#906b17` |
| 75 | `#866d12` |
| 90 | `#6f7725` |
| 105 | `#5b7930` |
| 120 | `#407c44` |
| 135 | `#2c7850` |
| 150 | `#196b40` |

分数越高越偏绿，越低越偏红，具体小数按原始值取色，显示整数时不改变底层映射。模型整体 IQ 仍来自跨档位历史末点，着色不会重新计算分数。缺失、无效数值保持中性灰 `#879083`，真实 0 分使用红色。数字、样本量和数据不足提示同时保留，绿色只表示分数较高。色标位于长图顶部，列出全部 11 个控制点；颜色常量、数字取色和图例共用 `IQ_COLOR_STOPS`。0–150 每 0.1 分采样检查时，数字在档位底色上的最低对比度约 4.56:1，截图脚本另检查实际渲染结果。

## 国内外与厂商分组

先显示国外，再显示国内；每家厂商有独立标题和连续的模型区域，厂商内部保留数据源顺序。地区与厂商顺序仅用于查找，不表示实力排名。当前快照分组如下：

| 区域 | 研发厂商 | 模型家族 | 模型数 / 档位数 |
| --- | --- | --- | --- |
| 国外 | OpenAI | GPT / Astra、Sol、Terra、Luna | 5 / 25 |
| 国外 | Anthropic | Claude | 2 / 10 |
| 国外 | Google | Gemini | 2 / 6 |
| 国外 | xAI | Grok | 1 / 4 |
| 国内 | DeepSeek | DeepSeek，含 DSH 版本 | 5 / 10 |
| 国内 | 智谱 · Z.ai | GLM | 2 / 6 |
| 国内 | 月之暗面 · Moonshot AI | Kimi | 1 / 3 |
| 国内 | 腾讯 · Tencent | 混元 / HY | 1 / 3 |

分组以模型研发厂商为准，`dsh-` 是运行环境标识，归到其底层模型的厂家；版本与各自数据仍独立展示。[Moonshot 官方页面](https://www.moonshot.ai/)列出 Kimi K3，[Z.ai 文档](https://docs.z.ai/guides/overview/overview)说明 GLM 家族，[腾讯公告](https://www.tencent.com/zh-cn/tencent-releases-and-open-sources-tencent-hy4-preview/)说明 HY4 的研发归属。现有模型 ID 显式映射到厂商，已识别家族的新版本按前缀分组；无法识别的名称放入单独的“待归类模型 / 厂商待确认”区域。

模型卡共用三列网格，桌面每张约 613 px；厂商有一个、两个或多个模型时，卡宽保持一致，末行不足三张也不拉伸。小厂商组可并排，例如 Google 与 xAI、智谱与月之暗面；组标题仍分别保留。卡片高度随档位数自然变化，避免少档位卡被强制撑高。平板改为两列，手机改为一列，所有断点均检查卡宽一致。图片与文本降级输出使用同一套分组规则，原始数据不做合并或改写。

图标使用[众测雷达](https://deng.codexradar.com/)公开页面的原始资源：Astra 星系、Sol 太阳、Terra 地球、Luna 月亮、GPT-5.5 星系系统，以及 DeepSeek、Grok、Kimi、GLM、Gemini、HY4、Claude 对应图标。同家族不同版本共享图标，通过完整 ID 区分。图标随插件本地保存、内嵌输出，未知模型使用雷达图形。来源清单见 [assets/models/README.md](../plugins/radar/assets/models/README.md)。

## 数据选择的用意

| 展示内容 | 数据来源 | 用意 |
| --- | --- | --- |
| 国内外 → 厂商 → 模型 | 本地研发厂商映射 + 上游模型 ID | 先定位熟悉的厂商，再比较同厂商的型号与档位；同类模型集中展示，减少来回寻找。 |
| 模型大字 IQ + 曲线 | `/iq-history` 的裸模型名序列，排除 `latest:` 和 `@effort` | 看同模型跨档位的整体历史变化。大字取本序列末点；若末点无效则显示缺失，不回退成旧分数。直角坐标系让变化幅度和时间跨度可读。 |
| 模型末点样本与时间 | 同一历史点的 `samples / timestamp` | 交代整体分数的证据规模与时效。缺历史时大字与曲线留空，档位格照常显示。 |
| 档位 IQ | `/intelligence-efficiency` 的 `iq` | 看具体推理档位的表现；与格内其他数值来自同一条效率记录，不混入跨频道综合 IQ。 |
| IQ 数字颜色 | 原始 `iq` → 全页固定的 0–150 色标 | 用连续红黄绿表示分数高低；同分同色，快速比较模型整体值和不同档位，推理档位名称本身不再决定颜色。 |
| 通过率 / F1 + 样本 | 同一记录的 `passed / total` | 在同一格交代效果与样本；连续频道显示 F1，浮点加权通过量不当作通过题数。 |
| 平均耗时 + API 等价费用 | 同一记录的 `average_minutes / average_price_usd` | 把效果与投入放在一起，比较加档是否值得等待和预算。当前聚合结构未提供逐项实测来源，标 `~` 估算，费用单位美元/次。 |
| 档位更新时间 | point 级 `source_updated_at` | 各档快照可能不同步；面板底部显示各档更新时间范围，HTML 悬停每格查看自身时间，统一 UTC。 |
| 缓存状态 | 效率 `meta.stale` + 历史 `HistorySeries.stale` | 效率缓存提示放页头，模型历史缓存提示放相应面板，分别说明。 |
| 数据不足提醒 | 历史有效点数、末点 `samples`、每档 `total / iq / passed` | 区分没有历史、仅一个时刻、样本量缺失、零样本、小样本、IQ 或评测得分缺失；标在实际受影响的模型和档位，避免把一个小样本高分当作充分证据。 |

图中 IQ 四舍五入为整数，未修改底层值；档位 IQ 的 HTML 悬停提示保留一位小数。`—` 表示缺失，真实 0 值保留。趋势纵轴固定 0–150，显示 `0 / 50 / 100 / 150` 刻度，避免窄幅波动被截断纵轴放大；横轴按实际时间间隔绘制，刻度对齐 UTC 整点或自然日，跨日窗口显示日期，短窗口显示时刻。起止日期和时刻另列图下。刻度文字使用独立 HTML 布局，保持 11 px，不随 SVG 宽高缩放；折线通过 SVG 绘制，线宽保持固定。密集采样点保留悬停信息，仅末点和孤立点显示圆点，避免折线变成一串珠点。只使用已有历史记录，缺失或无效点断线，不补零、不平滑生成新值；单点只画点和对应日期，提示暂不能判断趋势。各屏宽统一将曲线放在分数下方。无历史时使用紧凑提示行和时钟图标。模型 IQ 是众测评测指标，不等同于人类智商。

数据不足用暖琥珀提示块、感叹号和文字共同表达。模型级提示汇总历史缺失及受影响档位数，每个异常档位紧邻样本量显示具体原因。`0<n<30` 为本地前端“小样本”提醒线，常量为 `MATRIX_SAMPLE_REMINDER`；接口和现有配置没有提供统一阈值，因此明确标注“非上游统计判定”。该提醒不估算置信度，不把 `n≥30` 宣称为可靠或稳定，也不删除原始小样本分数。历史样本用末点自身的 `n`，不将各时刻样本相加；耗时、费用缺失单独保留 `—`，不据此判断 IQ 数据不足。文本降级保留相同原因和提醒线说明。

详细解释保留在本文，图内底部提供简短图例与数据来源。

## 接入与预览

`/radar`、`/radar 总览`、`/radar overview` 返回一张完整矩阵长图。使用 `/radar 总览 @pompeii-adjacency` 切换频道。`/radar 帮助` 和其他细分查询继续可用。

数据路径为 `handlers → RadarService.model_matrix() → RadarClient`，总览只读两个已有缓存端点，不逐模型发请求。本次公开快照包含 19 个模型、67 个档位，完整输出在同一张 PNG 中。渲染上限 20000 px，超限明确报错并走完整文本降级，不静默裁切。插件重载后生效。

```bash
# 获取一次公开只读快照并渲染
.venv/bin/python scripts/preview_ai_radar_matrix.py --live

# 调整样式后复用保存的同一快照
.venv/bin/python scripts/preview_ai_radar_matrix.py
```
