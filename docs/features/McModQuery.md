# MC 百科搜索（plugins/McModQuery）

在 mcmod.cn 搜索模组或资料，回复标题和链接（文字）。用户说明见 `/help mc`（见 [帮助](help_plugin.md)）。

## 命令

群聊、私聊均可，无权限要求。

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/mod <模组名>` | `/模组` | 搜索模组，默认前 3 条 |
| `/资料 <资料名>` | — | 搜索资料，前 5 条 |

两条命令的参数都注册为 `Args["rest", str]`，只接受一个不含空格的词。

## 配置

无。

## 数据

无。

## 已知问题

- `/mod <名字> <数量>` 永远不触发（无回复）：参数只收一个词，多出的数量让 Alconna 解析失败（`handlers.py:14`）；处理函数里解析数量的代码因此走不到。同理，带空格的名字（如 `/mod 机械 动力`、`/资料 安山 机壳`）也不触发。
- 处理函数里的格式提示（`格式：/mod <模组名> [数量]` 等）因参数必填而走不到；即使发出，`<…>` 也会被当成消息元素解析（见 [帮助](help_plugin.md) 的已知问题）。
