# 终末地冷启动提醒

状态：已实现。

冷启动时先向用户发一条文字，再继续原来的查询、拉数据和出图。热路径保持现在的行为，不插这条消息。

## 用户看到的

文字用 `matcher.send` 发出，不结束会话。后面的候选列表、图片或错误文案仍走原来的 `finish`。

> 终末地资料正在首次加载，可能需要十几秒，加载完会继续发送结果。

同一次命令只发一次。公共表已经发过时，后面的素材下载不再发第二条。提醒发出后查询失败，原来的错误文案照常结束这次命令。

同一时刻多个人打到冷启动，每个会话各发一条。底层下载仍由现有 HTTP 缓存合并。

## 什么时候发

参数、权限、绑定和账号选择先做完。这些马上就能回的结果不发提醒。确认这条命令要去拉公共资料或远程素材之后，再在下载前面发。

满足任意一条即发：

1. **本进程还没热过。** 这次进程还没有成功把 `I18nTextTable_CN` 放进内存。重启后第一次走默认 AKE 公共资料的命令会提醒。成功读完这张表之后，这条不再触发。
2. **这次要用的数据在内存和磁盘上都没有可用缓存。** 包括公共表和这条命令实际要请求的远程素材。进程中途清缓存、磁盘里没有对应条目、条目校验失败、AKE 版本变了导致旧路径对不上，都算。进程早就热过也再提醒一次。

磁盘上还有未过期的条目，或者还有条目、只需做一次 304 校验，算有缓存，不因为第 2 条提醒。

## 缓存各算什么

| 层 | 位置 | 是否参与冷启动 |
| --- | --- | --- |
| 公共表 | 内存 HTTP 缓存；磁盘 `data/cache/akedata-tables-v1.sqlite3` | 参与。代表表是 `I18nTextTable_CN` |
| 资料卡远程素材 | 命名空间 `endfield-assets`。立绘、技能图标、装备图标等。内存一份，磁盘 `data/cache/public-images-v1.sqlite3`（默认约 256 MiB，与表库分开） | 参与。只看这条命令实际会请求的 URL |
| 账号卡远程素材 | 命名空间 `endfield-account-ui-assets`，进同一个图片库 | 参与。账号详情、养成统计等会走到这里的命令 |
| 仓库自带小图标 | 插件目录里的安装文件 | 不参与 |
| 成品图 | `_CARD_CACHE`、`_LOADOUT_CACHE`、`_CALENDAR_CACHE`、`_CHALLENGE_RENDER_CACHE` 等 | 不参与。表和素材都在、只是重新出图时不发 |
| 抽卡图片 | 命名空间 `endfield-gacha-images` | 不参与。抽卡命令不在本次范围内 |

别人已经缓存过的别的立绘不算数。素材地址要等视图拼出来才知道，所以素材这项检查放在对应的 `_prepare_assets` 下载之前。

显式指定 FZ 或 Warfarin 时，不看 AKE 的进程热标记，只看它们自己的公共响应：内存和磁盘都没有才提醒。

## 怎么判断，且不把大文件读出来

提醒发在下载前面。存在性检查不读取十几 MB 的表或立绘正文。

- 内存：看 HTTP 缓存里有没有当前这条资源。
- 磁盘：只查元数据（键、校验时间、有效期）。现在的 `PublicImageDiskCache.get` 会读出整段内容，实施时要加一个不读正文的查询。
- 公共表的版本路径以当次 manifest 为准。manifest 约 2 KB。路径和已记住的成功路径不一致，就按没有缓存处理。
- 进程热标记在 `plugins/endfield/providers/akedata.py` 的 `_get` 里置位：路径以 `/I18nTextTable_CN.json` 结尾且返回成功。资料查询、养成、账号详情名称、持有率、影拓文案现在都走这个函数。

`/ef dev` 清掉 `akedata` 时，进程热标记一并清掉。清掉 `endfield-assets` 或 `endfield-account-ui-assets` 后，下一次缺这些图的出图会再提醒。

共享的 `_prepare_assets` 自己不发消息。由下面列出的命令在进入慢路径之前调用同一次命令内的检查，避免签到、日常把同名下载也带上提醒。

## 哪些命令会提醒

| 会提醒 | 时机 |
| --- | --- |
| 干员、武器、装备、关卡、物品、道具、敌人、词条的查询和搜索，含 `efop`、`efwp`、`efeq`、`efs` | 校验通过后、收集候选之前。出图前再查这次的素材 URL |
| 配装 | 参数已经合法之后、解析名字之前 |
| 版本日历 | 拉日历数据之前；出图前再查素材 |
| 奖章查看、档案库查看 | 读公共表或出图拉素材之前 |
| 影拓丰碑、战争回响 | 拉文案表之前。冷的文案表最多等 12 秒；出图前再查素材 |
| 养成统计、账号详情、基建、持有率 | 拉名称表或公共表之前；出图前再查素材 |

候选有歧义时，提醒在编号列表前面。用户回了编号之后不再发第二次。配装如果先要互动填参数，提醒放在参数收齐之后。

| 不提醒 | 原因 |
| --- | --- |
| 帮助、数据源、速算、别名、dev | 本地即可返回 |
| 绑定、解绑、账号列表、主账号 | 本地账号库或互动提问 |
| 签到、日常、抽卡、抽卡记录、抽卡同步、抽卡导入、资源流水 | 不走这套公共表冷启动；抽卡图片缓存不在本次范围内 |
| 奖章刷新、档案刷新 | 已有「正在抓取 AKEData …」 |
| 缺章、档案进度、档案条目 | 读本地快照和账号接口 |

## 不做的事

- 不把提醒和结果合成一条消息。
- 不改查询、出图或失败文案。
- 不为 Playwright 第一次出图单独加提醒。数据已经在缓存里、只是浏览器第一次启动偏慢时不发。
- 不在判断冷启动时把表或素材正文加载进内存。
