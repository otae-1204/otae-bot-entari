# Endfield 娱乐小队玩法设计草案

> 状态：概念整理，尚未进入实现。
>
> 目的：记录当前讨论所得方向，供后续继续取舍、补充和平衡；本文不是最终需求或概率承诺。

## 1. 一句话概念

在 Endfield 插件内增加一套与真实游戏数据分离的原创“边境事务所”娱乐玩法：玩家每日免费招募原创队员、组成四人小队，并投入纯虚拟货币执行一次性随机行动，从收藏、队伍组合、随机事件和虚拟收益中获得乐趣。

## 2. 设计目标

### 2.1 核心体验

- 保持低交互：每项操作均为“一条用户指令，一条机器人结果”。
- 不设置需要等待、确认、封盘或连续选择的流程。
- 日常循环足够短：每日招募、查看或调整队伍、执行一次随机行动。
- 随机结果既有赌博感，也有队伍养成和长期收藏价值。
- 结果优先以一张信息完整的图片卡呈现，失败同样应有有趣的事件叙事。

### 2.2 明确边界

- 玩法中的队员为原创角色，不必使用游戏内现有干员。
- 娱乐队员的职业、稀有度、能力和强弱不代表真实游戏设定。
- 不读取或消耗玩家真实账号中的源石、嵌晶玉、武库配额等资源。
- 娱乐招募不模拟、不暗示真实卡池概率。
- 虚拟货币不能兑换现金、真实物品、账号资源或其他有价权益。
- 不加入实时战斗、多人房间或强制等待其他玩家响应的交互。

## 3. 主题与包装

暂定主题为“边境事务所”。玩家经营一支不太正规的外勤队伍，通过招募各种原创成员，承接勘探、押运、遗迹探索和黑市委托。

整体风格可以在终末地工业科幻氛围上加入轻喜剧元素，例如：

- 暴躁医疗机器人
- 戴墨镜的源石虫
- 总是迷路的侦察员
- 退休爆破员
- 实习运输员
- 赌运货无人机
- 没有执照的维修师
- 每次都算错账的会计

原创角色既可以是人类，也可以是机器人、动物、怪物或用途可疑的工业设备。

## 4. 虚拟经济

### 4.1 虚拟货币

暂称“协议票”，仅供娱乐玩法使用。

主要来源：

- 新玩家启动补给
- 每日首次参与补给
- 随机行动结算
- 重复满级队员转化
- 成就、图鉴与赛季奖励
- 远征中发现的额外物资

主要消耗：

- 随机行动投入
- 免费次数以外的受限招募
- 少量纯展示型收藏品、称号或结果卡皮肤

### 4.2 防止无法继续游玩

- 每日补给自动发放，不单独设置“领取”指令。
- 玩家余额不足时提供有限的破产救济。
- 可设计“源石虫存钱罐”等遗物，在连续失败后自动提供补给。
- 设置单局最大投入，避免误操作一次清空全部余额。

### 4.3 经济原则

- 所有余额变化记录流水，下注与结算必须在同一个事务内完成。
- 概率、最终成功率、结算倍率和余额变化应在结果中清楚展示。
- 长期预期收益应通过模拟确定，不能只凭感觉配置倍率。
- 高稀有度队伍可以提高稳定性，但不能形成无风险、无限增长的正收益循环。
- 暂不开放玩家间自由转账和可交易队员，避免刷号与纠纷。

## 5. 原创队员系统

### 5.1 角色池

首版建议准备约 24～30 名固定原创队员。固定角色比完全随机生成更容易形成辨识度、图鉴目标、角色故事和稳定的美术资产。

每名队员拥有：

- 唯一 ID
- 名称和简短设定
- 稀有度：B / A / S / EX
- 职业
- 基础行动力
- 幸运或专长参数
- 固定核心能力
- 可随机获得的附加特质
- 头像、立绘或图标
- 合同等级（由重复获得提升）
- 个人履历统计

采用 B / A / S / EX 等娱乐稀有度，避免与真实游戏星级混淆。

### 5.2 职业建议

| 职业 | 主要作用 |
| --- | --- |
| 护卫 | 提高行动成功率，降低严重事故影响 |
| 侦察 | 降低危险事件概率，提高隐藏区域发现率 |
| 寻宝 | 提高高倍率、宝箱和遗物出现率 |
| 维修 | 失败时返还部分投入，修复负面事件 |
| 后勤 | 增加协议票、招募券和碎片产出 |

职业作用应偏向改变事件分布和风险结构，不必模拟复杂战斗数值。

### 5.3 随机特质示例

- 幸运儿：小概率使结算倍率翻倍。
- 胆小鬼：失败损失减少，但大奖概率降低。
- 赌徒：成功倍率提高，失败时不享受普通返还。
- 拾荒者：行动后可能额外带回协议票。
- 招募官：行动后可能发现招募券或新队员。
- 医疗保险：失败时概率返还部分投入。
- 乌鸦嘴：面板优秀，但偶尔触发严重事故。
- 违规改装：提高爆发收益，同时增加故障概率。

每名队员建议最多保留一个主特质和一个副特质，避免角色信息过载。

### 5.4 重复队员处理

- 重复获得时自动提高合同等级。
- 合同等级提供有限数值提升或解锁角色能力。
- 满合同后再次重复，自动转换为协议票或招募券碎片。
- 特定合同等级可以触发随机特质强化或特殊形态。
- 全部自动结算，不要求玩家逐个确认或分解。

## 6. 每日招募

建议指令：

```text
/ef 娱乐 招募
```

基本规则：

- 每日自动获得 3 次免费招募。
- 默认一次抽完当天剩余免费次数，并用一张结果卡汇总。
- 可设置最低稀有度保底。
- 连续一定次数没有获得新成员时，下次保证出现未拥有成员。
- 娱乐招募采用独立概率，并在帮助中明确不代表真实游戏卡池。

示例结果：

```text
边境事务所 · 今日招募

NEW  S级 暴躁医疗机器人
     特质：医疗保险

UP   A级 退休爆破员
     合同等级 +1

NEW  B级 实习运输员
     特质：幸运儿

今日免费次数：0/3
队员图鉴：14/30
```

### 6.1 其他获取方式

- 随机行动中触发“有人要求入队”。
- 行动掉落招募券碎片，达到数量后自动招募。
- 首次达成特定倍率或事故条件时解锁隐藏队员。
- 连续失败后获得特殊“破产救济队员”。
- 每周首次完成高风险行动时，保证获得一名未拥有的低或中稀有度成员。
- 赛季活动提供独立的纪念队员或外观，但不制造绝版强度差距。

## 7. 四人小队

### 7.1 基本规则

- 每支队伍固定四名成员。
- 当前编队持久保存，执行行动时自动使用。
- 高稀有度提高基础能力，职业、特质和羁绊决定玩法差异。
- 队伍加成应设置上限，避免后期将随机玩法变成必胜玩法。
- 队员不永久死亡，不设置需要频繁处理的伤病和体力系统。

### 7.2 指令

```text
/ef 娱乐 队伍
/ef 娱乐 编队 <编号1> <编号2> <编号3> <编号4>
/ef 娱乐 自动编队
```

每条指令均立即完成并回复一张队伍卡。自动编队可根据综合稳定性选择队员，但不需要构建复杂的攻略推荐系统。

### 7.3 队伍羁绊

特定成员同时出战时自动触发组合效果：

```text
「不靠谱维修组」
暴躁医疗机器人 + 实习运输员
失败返还率 +15%，事故率 +5%
```

```text
「这条路肯定没问题」
迷路侦察员 + 赌运货无人机
隐藏区域概率 +20%，空手而归概率 +10%
```

羁绊应包含收益与代价，避免存在唯一最优固定队伍。隐藏和喜剧型羁绊可以成为图鉴的一部分。

## 8. 一次性随机行动

所有行动都必须满足：输入一次指令，服务器完成随机计算、更新状态并回复一次结果；不保留等待玩家继续选择的临时流程。

### 8.1 标准远征

```text
/ef 娱乐 远征 200 冒险
```

风险档位：

- 稳健：高成功率、低倍率。
- 冒险：中等成功率、中高倍率。
- 疯狂：低成功率、极低概率获得十倍以上回报。

示例结果：

```text
边境事务所 · 废墟远征

出战：
暴躁医疗机器人｜戴墨镜的源石虫
退休爆破员｜实习运输员

基础成功率：54%
队伍修正：+13%
最终成功率：67%
随机值：72

行动失败！
医疗机器人触发「医疗保险」
返还投入的 50%

投入：200
返还：100
额外发现：招募券碎片 ×1
余额：1380
```

### 8.2 可扩展行动类型

| 行动 | 玩法侧重 |
| --- | --- |
| 远征 | 标准成功率与随机倍率，作为基础玩法 |
| 押运 | 成功率较高，可能遭遇劫掠、货损或意外加单 |
| 擂台 | 与系统生成的队伍立即模拟对战，无需真人接受 |
| 遗迹 | 收益波动极大，偏向稀有队员、遗物和隐藏事件 |
| 黑市 | 随机获得赝品、普通货物、稀有遗物或神秘合同 |

不同职业可以在不同模式中发挥优势，引导玩家组建多种队伍。

### 8.3 每日世界状态

每天生成一个全群共享的环境修正，并自动显示在行动结果中：

- 磁暴天气：机械队员行动力下降，寻宝收益提高。
- 黑市繁荣：协议票收益提高。
- 招募热潮：招募券和新队员出现率提高。
- 运输管制：押运倍率提高，成功率下降。
- 源石虫迁徙：特殊角色和收藏品可能出现。
- 安全生产月：失败最多只损失一半投入。
- 审计风暴：高额投入更容易触发负面事件。

每日状态让同一条远征指令每天产生差异，但不增加查询或选择步骤。

## 9. 长期收集与成长

### 9.1 队员个人履历

自动累计：

- 出战次数
- 成功与失败次数
- 累计带回协议票
- 触发特质次数
- 最高结算倍率
- 制造事故次数
- 被救援次数
- 发现隐藏区域和队员次数

履历用于生成个性化称号和故事，而不只用于提高数值。

### 9.2 遗物系统

遗物是账号级被动收藏品，例如：

- 破损指南针：更容易发现隐藏事件，也更容易迷路。
- 过期保险单：每日第一次失败返还部分本金。
- 可疑骰子：高倍率概率提高，普通收益降低。
- 招募部门印章：每日免费招募次数偶尔增加。
- 源石虫存钱罐：连续失败后自动提供救济。
- 红色紧急按钮：极低概率重投一次失败结果。

遗物不应扩展成多部位装备和繁琐强化。可以由系统自动携带，或只允许设置一个当前遗物。

### 9.3 图鉴和隐藏内容

- 原创队员档案
- 队伍羁绊
- 遗物图鉴
- 事故报告
- 黑市赝品
- 稀有远征地点
- 隐藏结局
- 高倍率纪念章
- 特殊队员形态

解锁内容应随正常行动自动入库，不额外设置“领取奖励”步骤。

## 10. 轻量竞争

### 10.1 系统宿敌

设计若干固定竞争事务所，在行动中随机出现：

- 正经安保公司
- 没有营业执照的运输队
- 全员机器人的维修协会
- 源石虫互助会
- 每次都报错账的会计事务所

宿敌用于提供对抗叙事和特殊随机事件，不需要其他真人玩家参与。

### 10.2 影子队伍挑战

```text
/ef 娱乐 挑战 @某人 200
```

读取对方当前队伍快照并立即模拟结果：

- 不要求对方确认。
- 不扣除或改变对方资产。
- 只结算发起者的投入。
- 不允许通过挑战给对方转移收益。

### 10.3 周榜与赛季

可记录：

- 本周最高倍率
- 最大单局盈利
- 最赚钱队员
- 事故次数最多的队伍
- 最倒霉事务所
- 保险触发次数

队员、图鉴和收藏永久保留，仅赛季积分和周榜重置。奖励以称号、纪念品和少量招募资源为主，避免强者通过排行榜持续滚雪球。

## 11. 建议命令面

首版控制在以下命令：

```text
/ef 娱乐
/ef 娱乐 招募
/ef 娱乐 队员 [页码]
/ef 娱乐 队伍
/ef 娱乐 编队 <编号1> <编号2> <编号3> <编号4>
/ef 娱乐 自动编队
/ef 娱乐 远征 [投入] [稳健|冒险|疯狂]
```

后续按需要增加：

```text
/ef 娱乐 押运 [投入]
/ef 娱乐 擂台 [投入]
/ef 娱乐 遗迹 [投入]
/ef 娱乐 黑市 [投入]
/ef 娱乐 遗物
/ef 娱乐 履历 [队员编号]
/ef 娱乐 挑战 @用户 [投入]
/ef 娱乐 排行
```

帮助文本应同时给出：标准语法、别名、默认值、参数范围、余额不足提示和无效输入行为。

## 12. 技术落点建议

后续如进入实现，可在 Endfield 插件内保持独立模块边界，例如：

```text
plugins/endfield/entertainment_models.py
plugins/endfield/entertainment_catalog.py
plugins/endfield/entertainment_service.py
plugins/endfield/entertainment_store.py
plugins/endfield/entertainment_draw.py
```

建议持久化内容：

- 玩家娱乐钱包
- 余额流水
- 已拥有队员与合同等级
- 队员特质和个人履历
- 当前四人编队
- 每日免费招募使用量
- 招募保底状态
- 遗物和图鉴解锁
- 周榜与赛季统计

实现原则：

- 使用 SQLite 持久化，避免只保存在进程内存中。
- 钱包扣款、随机结算、奖励入账和流水写入使用原子事务。
- 随机数使用适合该用途的安全随机源。
- 保存必要的概率版本、随机结果、倍率和事件 ID，以便排查争议。
- 所有概率逻辑尽量放在纯函数中，通过大量模拟和单元测试检查收益分布。
- 不复用真实账号资源表，不依赖森空岛账号绑定。
- 命令解析、帮助、无效参数、余额不足、每日重置和重复结算都需要测试。

## 13. 分阶段路线

### 第一阶段：完整基本循环

1. 协议票钱包与流水。
2. 原创队员基础目录。
3. 每日三次免费招募。
4. 重复队员与合同等级。
5. 四人编队和自动编队。
6. 单次远征结算与结果卡。

### 第二阶段：增加重复可玩性

1. 队员随机特质。
2. 队伍羁绊。
3. 每日世界状态。
4. 押运、擂台和遗迹。
5. 队员个人履历。

### 第三阶段：长期内容

1. 遗物与图鉴。
2. 隐藏队员和特殊形态。
3. 系统宿敌。
4. 影子队伍挑战。
5. 周榜、赛季称号和纪念内容。

优先级最高的扩展组合是“随机特质 + 队伍羁绊 + 每日世界状态”：它们可以显著改变每局结果，又几乎不增加交互步骤。

## 14. 暂不建议加入

- 手动回合制战斗。
- 需要双方确认的实时 PvP。
- 限时房间、封盘和等待开奖。
- 多部位装备、强化石、洗词条等重度养成。
- 需要频繁处理的体力、伤病和永久死亡。
- 玩家间自由转账、自由交易和可兑现资产。
- 每日大量任务与逐项领取按钮。
- 直接套用真实终末地干员强度、真实卡池或账号资源。

这些设计会明显增加维护和交互负担，也容易让娱乐小功能膨胀成另一套需要长期运营的完整游戏。

## 15. 后续需要决定的问题

- 正式主题名使用“边境事务所”还是其他名称。
- 首发队员数量、角色风格和美术方案。
- 是否保留源石虫等终末地氛围元素，或采用完全原创世界观。
- 每日免费招募次数和保底规则。
- 协议票的启动余额、每日补给和最大投入。
