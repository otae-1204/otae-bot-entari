# 终末地账号绑定流程

`/ef 绑定`（及别名 `/ef 添加账号`）只支持私聊，按提示依次选择服务器、绑定方式，
提交 Token 或手机号与短信验证码，最后选择要绑定的角色。

## 选择角色

账号下只有一个角色时直接绑定。有多个角色时，机器人列出序号、昵称、服务器和 UID：

- 回复列表前面的**序号**，或直接回复列表里的**游戏 UID**，两者可以混用；
- 一次可以回复多个，用空格、逗号、顿号、分号等分隔，例如 `1、3`、`1 1095714689`、
  `UID 1095714689`；全角数字和 `1号`、`1.` 也能识别；
- 回复“全部”绑定列表中的所有角色。

只要有一项不在列表里（序号越界、UID 不属于该账号、其他文字），机器人回复
“编号无效，请回复列表前面的序号（或列表中的 UID）”并重新列出角色，最多询问 3 次；
3 次都无效才取消绑定。

## 取消与超时

每一步都可以回复“取消”（或 `cancel`、`q`、`quit`）退出。两种结束方式提示不同：

| 情况 | 提示 |
| --- | --- |
| 用户回复“取消” | 已取消绑定。 |
| 等待回复超时 | 等待回复超时，绑定已取消；需要时请重新发送 /ef 绑定。 |
| 选择角色连续 3 次无效 | 连续 3 次未选中有效角色，绑定已取消；需要时请重新发送 /ef 绑定。 |

各步骤的等待时间：选择服务器和绑定方式 90 秒、手机号 90 秒、验证码 120 秒、
Token 150 秒、选择角色每次 120 秒。超时时 Entari 会先发送一条“等待超时”。

## 日志

### 步骤日志

绑定的每一步记一条 INFO 日志，前缀 `[endfield-bind]`，包含 QQ 号和步骤名，
不含手机号、验证码或 Token：

| step | 含义 |
| --- | --- |
| `start` | 开始绑定 |
| `region` | 已选服务器（`provider=cn`/`skport`） |
| `method` | 已选绑定方式（`token`/`sms`） |
| `send_code` / `code_sent` | 请求发送短信验证码 / 已发送 |
| `verify` / `verified` | 校验验证码 / 校验通过 |
| `token_received` | 收到 Token |
| `roles` | 查到的角色数 |
| `select` / `select_invalid` | 选中的角色数 / 第几次输入无效 |
| `done` | 完成，含新增、更新和当前绑定总数 |
| `cancel` / `timeout` / `invalid` | 用户取消 / 等待超时 / 选择多次无效，`at=` 为所在步骤 |
| `abort` | 手机号、验证码格式不对或未识别的选项，`at=` 和 `reason=` 说明原因 |
| `failed` | 官方接口报错，含 `operation` 和 `code` |

### `[message]` 日志脱敏

Entari 内置的 `record_message` 插件会把收到的每条消息写进 `[message]` 日志。
`otae_bot/adapters/message_log.py` 在启动时给这个日志加了脱敏：

- 所有消息中的大陆手机号显示为 `138****1234`；
- 绑定（以及小黑盒抽卡记录导入）对话进行期间，该用户发来的 4～8 位数字验证码显示为 `******`，
  16 个字符以上、像 Token 的字符串显示为 `<已隐藏>`；
- 序号、“取消”、10 位角色 UID 等其他内容照常记录，其他用户和对话结束后的消息不受影响。

插件的交互流程可以用 `otae_bot.adapters.message_log.sensitive_input(user_id)`
包住需要用户输入凭据的对话。
